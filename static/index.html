Setting up a new Kindle
  1. Plug the Kindle into this Mac and click Install at the top. It copies the scripts and your Playbills onto it.
  2. Eject it. In Jobman, turn on Wi-Fi SSH, then run ssh root@<kindle-ip> 'sh /mnt/us/playbills/install_cron.sh' (password kindle).
  3. Turn SSH off again. From then on everything syncs over Wi-Fi while this app is running.
